# 侦察兵技能修复报告

目标版本：Minecraft 26.1.2。

## 修复内容

| 技能 | 原因与修改 |
| --- | --- |
| 1：二级充能 | 按当前设计依次消耗两次充能，耗尽后开始冷却。只在冷却已结束且充能为空时补满，避免每次点击重复补充造成无限使用。 |
| 1：火矢、冲击、穿透 | 发射时复制武器到箭的 `weapon`，设置 `Fire` 和 `PierceLevel`，使原版火焰、Punch 击退和穿透生效。伤害仍使用射出时的项目伤害快照。 |
| 1：命中归属 | 原入口搜索 `HurtTime:10s` 的最近敌人，同一 tick 穿透多个目标时可能重复伤害第一人。现在 `arrow_effect` 的两个有序 `post_attack` 效果分别取得实际箭和实际受击者，再执行伤害、标记、爆炸与连锁；保留 `#bypass` 排除规则。 |
| 1：发射特效 | 增加射手可见的 crit 粒子及箭起点粒子。 |
| 2：爆炸反馈 | 稍微增强粉尘粒子，并加入爆炸音效。 |
| 3：落地反馈 | 增加落地音效、末地烛粒子和闪光；确认离地后不再因 3 秒计时结束而丢失落地触发，兼容缓降和长距离下落。保留已有的位移 `power:2`。 |
| 4、7：F 输入 | 弓弩初始化补充 `s_trigger`；已有带 `core:inter/arrow_effect` 触发附魔的职业弓弩可走兼容分派，不依赖可能已经丢失的 `custom_data.range`。普通原版弓弩不能借此释放技能。换手缓存改用物品实体，兼容空副手及带 `Offhand` 标记的盾牌。 |
| 5：投掷与外形 | 改为小村民，移除阻止运动的 `NoAI`，应用沿视线的初速度；移动属性为 0，落地后不会自主走动。 |
| 5：远程仇恨 | 改为按需建立反击记录，避免不断重载敌人 NBT 中断骷髅拉弓，具体机制见下文。 |
| 6：连锁特效 | 延长电弧轨迹显示，增加电火花、闪光与电击音效。 |
| 8：使用减速 | 使用 `use_effects.speed_multiplier:1`，移除旧的移动属性补偿。只用 `if items` 检查主手弓弩的 `core.scout8.active` 标记；失去技能时将该标记改为 `false` 并设回 `0.3`。背包、副手和掉落物不扫描，换到主手后惰性更新。 |

## 诱饵如何吸引仇恨

诱饵每 10 tick 检查 10 格内的敌人。对尚未受当前诱饵吸引、或最近攻击者记录已被替换的敌人，执行以小村民为来源的零伤害 `minecraft:mob_attack`，建立原版最近攻击者记录；随后单次更新 `ticks_since_last_hurt_by_mob`，使反击 AI 选择小村民。时间戳也兼容刚生成、`tickCount` 为 0 的敌人。

敌人的记录仍指向该诱饵时，后续检查直接跳过。原实现每隔半秒改写敌人 NBT，会重新加载其战斗状态，导致骷髅拉弓不断被打断。现在不再重复这一步，骷髅能选择小村民并完成射箭。诱饵移除时会清理关联临时标记；失明、受击次数、主动引爆及冷却规则保留。

## 验证方式

使用本机 26.1.2 命令解析器和隔离的临时 GameTest 世界。运行 `tests/check_scout.ps1`，以及 `tests/test_scout_runtime.ps1` 的默认、`-Skills58`、`-Fixes` 场景；均通过 `-MinecraftRoot` 传入游戏目录。

结果：114 个函数编译和两组宏参数实例化通过；1–4 技能 39 项、5–8 技能 53 项、新增修复场景 27 项断言通过，共 119 项。运行时无函数加载或序列化错误，`git diff --check` 通过。

新增场景覆盖实际左键组件攻击、真实 F/潜行 F 数据包与库存进度、盾牌保留、普通弓弩负例、同 tick 多目标穿透、射出后换武器和附近其他箭的干扰、火矢与冲击、长时间下落、粒子/音效包、组件字段保留和恢复。诱饵测试推进 100 次骷髅 AI tick，确认目标是小村民，并检查确实生成了该骷髅射出的箭。

修改后执行 `/reload`。未新增资源包内容；粒子指令及反馈包已检查，客户端第一人称的最终观感仍需在游戏内观察。

## 2026-09-14：重复输入与副手数据修复

二级充能此前在每次 cast 开头重新补满，和耗尽后才开始冷却的修改组合后，形成反复 2→1、永远不进入冷却的问题。现在冷却期间拒绝释放，仅在充能为空且冷却结束时补满；保留用户调整后的耗尽起算方式。

第 8 技能的副手恢复原先读取旧版 `Inventory[{Slot:-106b}]`。26.1.2 副手存放于 `equipment.offhand`，读取失败会留下默认的备份标志，从而错误删除整个 custom_data。现已修正路径、加上备份存在检查，并修正仅副手有备份时的清理入口。F 分派以职业弓触发附魔识别，兼容已有自定义数据丢失的弓；不会臆造已经丢失的原物品数据。

新增测试让生产 `core:inter/tick_load` 附魔驱动公共冷却与左键组件刷新，连续三轮执行左键、F、潜行 F、潜行左键，以及诱饵主动引爆。额外覆盖 F 换手期间副手组件恢复触发库存进度的时序、自定义字段保留、每 tick 冷却恰好递减一次，以及剩余一次充能经过多个 tick 后不会补满。

本轮验证：默认 1–4 场景 39 项、5–8 场景 53 项、输入与恢复场景 69 项，共 161 项断言通过。等级从二级切到一级时，也会立即将可用充能限制为一次。

## 多重射击与第 8 技能主手更新

左键速射接入多重射击：未附魔为 1 支箭，1 / 2 / 3 级及以上分别为 3 / 5 / 7 支箭，每次只消耗一次充能。侧箭按视线局部坐标左右展开，每级增加一对相隔 10° 的箭；每支箭保留武器附魔、伤害、射手及连锁射击数据。齐射使用独立快照，避免射箭回调覆盖临时数据，并保留原蓄力进度。

第 8 技能改为按主手弓弩标记更新组件：拥有技能时设置速度倍率 1，取消技能或更换职业后设置 0.3。仅主手状态变化时写入组件，不再扫描背包、副手和掉落物。放入背包或转交的武器在再次被主手持有时更新；不再备份和恢复任意原始速度倍率。其他 custom_data 字段保留。

回归场景包含弓、弩的多重射击 0 / 1 / 2 / 3 / 4 / 255 级，平视、仰视与俯视，以及主手技能选择、取消、重选、职业切换和 F 键交换。

验证结果：Minecraft 26.1.2 下，104 个函数解析及宏实例化通过；默认场景 39 项、5–8 场景 53 项、修复场景 261 项断言通过，共 353 项。运行时未出现函数加载或序列化错误。
